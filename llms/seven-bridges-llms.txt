## API Reference
- [Get details of a project](https://docs.sevenbridges.com/reference/get-project-details.md): This call returns the details of a specified project.
- [List files (primary method)](https://docs.sevenbridges.com/reference/list-files-primary-method.md): This call returns a list of files and subdirectories in a specified project or directory within a project, with specified properties that you can access. The project or directory whose contents you want to list is specified as a query parameter in the call. Further properties to filter by can also be specified as query parameters.   Note that this call lists both files and subdirectories in the specified project or directory within a project, but not the contents of the subdirectories. To list the contents of a subdirectory, make a new call and specify the subdirectory ID as the `parent` parameter.  Don't forget that projects on the Platform are specified by their [short names](doc:the-api#identifying-projects-users-apps-files-tasks-and-inputs).  Further file properties to filter by can also be specified as query parameters.
- [Get your current rate limit status](https://docs.sevenbridges.com/reference/get-your-current-rate-limit-status.md): This call returns information about your current rate limit. This is the number of API calls you can make in five minutes. This call also returns information about your current instance limit.
- [API status codes](https://docs.sevenbridges.com/reference/api-status-codes.md)
- [Start a bulk import job](https://docs.sevenbridges.com/reference/start-a-bulk-import-job.md): This call lets you perform a bulk import of files from your volume (either Amazon Web Services or Google Cloud Storage) into your project on the Platform.  You can use this call to either import files to a specific folder or a project but you can also use it to import a folder and its files into another destination folder while preserving folder structure (see below). One call can contain up to 100 items.   Learn more about using the Volumes API for [Amazon S3](doc:aws-cloud-storage-tutorial) and for [Google Cloud Storage](doc:google-cloud-storage-tutorial).
